## 口令词汇（三语 · 体感细节在此扩展）

> 这一节最适合你用中文先写出想表达的体感，再让我校准英德。

**呼吸**

| 中文 | English | Deutsch |
|---|---|---|
| 吸气 | inhale | einatmen |
| 呼气 | exhale | ausatmen |
| 深长地呼吸 | breathe deeply | tief atmen |
| 屏息 / 保持呼吸 | hold the breath | den Atem halten |
| 每个呼吸 8 秒 | 8 seconds per breath | 8 Sekunden pro Atemzug |

**动作与方向**

| 中文 | English | Deutsch |
|---|---|---|
| 向上 / 向下 | up / down | nach oben / nach unten |
| 向前 / 向后 | forward / back | nach vorn / nach hinten |
| 向右 / 向左 | to the right / left | nach rechts / nach links |
| 换另一侧 | switch sides | die Seite wechseln |
| 回到中间 | back to center | zurück zur Mitte |
| 抬起 / 落下 | lift / lower | heben / senken |
| 伸展 / 弯曲 | stretch / bend | strecken / beugen |
| 扭转 | twist | drehen |
| 延展 / 拉长 | lengthen | verlängern |

**身体部位**

| 中文 | English | Deutsch |
|---|---|---|
| 脊柱 | spine | die Wirbelsäule |
| 肩膀（放松下沉） | shoulders (relax down) | die Schultern (sinken lassen) |
| 骨盆 / 髋部 | pelvis / hips | das Becken / die Hüften |
| 手掌 / 脚掌 | palms / soles | die Handflächen / die Fußsohlen |
| 腹部 / 胸腔 | belly / chest | der Bauch / der Brustkorb |

**保持与放松**

| 中文 | English | Deutsch |
|---|---|---|
| 保持这个姿势 | hold the pose | halte die Haltung |
| 放松 | relax | entspanne dich |
| 慢慢解开姿势 | release the pose | löse die Haltung |
| 休息 | rest | ruh dich aus |

### 备注

- **Crooked Monkey（前臂支撑斜猴式）**、**Figure Four（四字式）** 是 Pocket Yoga 自创名，中德都无固定标准译法，给的是描述性翻译；视频里可加动作说明。
- **Wheel** 中文「轮式」、德文 **Rad**（Urdhva Dhanurasana）；PDF 里把准备/半轮/全轮分开了，已对应保留。
- 左右成对的体式录制时补 **右/左 · rechts/links** 即可。
- 你在中文列改动后告诉我，我会同步校准对应的英文与德文。
