## B. 坐立拉伸序列（段 7-8）（🎵 Respite）

### 坐立序列（左侧）

#### 头碰膝前屈（Janu Sirsasana）

坐到垫子上，弯曲右腿，右脚掌放左大腿内侧。

- **吸气**双手上举；**呼气**身体转向伸直的左腿
- **吸气**继续向上；**呼气**双手带上半身**向前向下**，视线先看脚趾方向
- **不要急着抓脚，让呼吸带动身体**，慢慢用右手抓左脚外侧
- 感受最紧张处——伸直腿后侧或弯曲腿小腿
- **停五个深长呼吸**

#### 马里奇扭转（Marichyasana）

**吸气**立直坐起。**呼气**把弯曲的腿向内旋转90度，脚掌放左膝外侧。

- **吸气**立直，双手环抱右膝
- **呼气**向右后侧扭转
- 挑战：左臂从右膝外侧伸直，或绕右大腿外侧、双手身后相扣——**马里奇式**
- **停三个呼吸**

#### 扭转头碰膝

回坐姿，环抱右腿上下轻拉，右脚放左大腿内侧。

- **吸气**向右旋转；**呼气**右手找左侧腰，可与右脚相扣
- **吸气**伸展左臂；**呼气**左臂带上半身**向前向下**，右膝渐渐靠近地面
- **停五个呼吸**

#### 指南针式（Parivrtta Surya Yantrasana）

> *这是本课程的高级变体，量力而行*

**吸气**双手抓右脚跟，慢慢伸展右膝，上半身直立。

1. **小腿与额头靠近三次**（感受腿后侧的伸展）
2. 若能轻松靠近：右手从右腿内侧穿过按压地垫，手指朝内，右大腿放右大臂上
3. 左手抓右脚外侧，慢慢伸直右腿，视线看左侧——**指南针式**
4. **停三个呼吸**

#### 反桌式 → 狂野式

慢慢放下右腿，右脚踩地，双手身后推地，身体抬起——**反桌式**，停2个呼吸。

**吸气**左手推地，右手放身体侧面，双腿不动，身体面向左侧——**狂野式**，动态三次。

最后一次停留在上方，右手向地面移动尝试触地。

## C. 大休息式（段 9）（🎵 Softhearted）

来到坐姿，**双脚掌相对，膝盖向两侧打开**——**束角式**。

慢慢向后躺下——**仰卧束角式**，双臂放松在身体两侧，掌心向上，停留3个呼吸，放松。

之后慢慢把双腿伸直——**大休息式（挺尸式 / Savasana）**。

让呼吸自然流动，**完全放松身体每一个部位**：
- 从脚趾……双腿……腹部……
- 胸腔……肩膀……双手……
- 颈部……面部……
- 直到音乐结束。

> 🌙 大休息式不是"睡觉"，而是**有意识的彻底放松**。这是整节课所有努力的汇聚点，也是身体整合所有练习的时刻。

## D. 本学期回顾：10周学习路径

```
第1周  呼吸与空间        → 坐立冥想、呼吸感知
第2周  四角板凳与根基    → 手掌支撑、猫牛式
第3周  站立体式详解      → 山式、战士系列、三角式
第4周  站立序列流动      → 完整拜日串联 + 鸽式
第5-6周 右侧镜像练习    → 对称觉察、前屈深化
第7-8周 平衡挑战        → 战士三、鹰式
第9-10周 扭转与大休息   → 坐立拉伸、指南针、大休息
```
