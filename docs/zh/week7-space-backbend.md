# 第7-8周：平衡挑战与后弯空间

**导言**：进入课程的第二阶段。在建立了扎实的站立基础后，我们开始挑战单腿平衡——战士三、鹰式。平衡体式的核心不是"不倒"，而是在动态中找到内在的宁静。

---

## A. 本周核心主题：动态平衡

### 平衡的真正含义

单腿平衡时，身体永远在微小地调整。这种"不完美"正是练习的核心：
- **不要试图"固定"自己**——允许微小的晃动
- **呼吸是锚**——当你开始摇晃时，不要屏气，深呼吸反而能帮你重新找到中心
- **视线是辅助**——找到地面上一个固定点，帮助集中注意力

> 💡 就像在水面上冲浪——不是抵抗水波，而是顺应并在其中找到平衡。

---

## B. 平衡挑战序列（段 6）（🎵 音乐4）

### 过渡：拜日串联

从山式开始，进入平衡挑战前先通过一轮拜日串联激活全身：

**山式** → **吸气幻椅式** → **呼气前屈** → **吸气抬头** → **呼气迈步到平板** → **吸气平板前移** → **呼气四柱** → **吸气眼镜蛇/上犬** → **呼气下犬**，停2个深长呼吸。

### 战士三 → 飞机战士（左侧）

**吸气**抬左腿向后，**呼气**迈左脚到双手之间。**吸气**双手上举——**战士一式**，2个呼吸。

→ **吸气**重心转到前脚掌；**呼气**慢慢抬后脚：

| 进阶层级 | 动作描述 | 停留 |
|---------|---------|------|
| 基础 | 抬后脚，保持弯曲 | 2个呼吸 |
| 战士三 | 伸直后腿同时伸直前臂，身体成T字形 | 2个呼吸 |
| 飞机战士三 | **吸气**双手向身后摆动到与腿同高 | 2个呼吸 |

**吸气**双手带后腿立直，手臂举高（腿可屈可伸）。

> **进阶变体**：立直后，用同侧手抓住大脚趾，吸气慢慢向前伸直腿；再吸气把腿向侧面打开，视线转向反侧，停2个呼吸。

### 抱膝 → 侧展 → 鹰式（左侧）

**吸气**双臂环抱双膝站立。**呼气**慢慢伸直右手，视线转向右手指尖，**伸展右侧**，停2个呼吸。**吸气**身体转正。

进入**鹰式**：
- **吸气**双臂前平举，**右臂从下方绕过左臂**，掌心相对
- **呼气**：**右腿跨过左大腿**，脚尖勾小腿后侧
- **屈膝下坐**，脊柱立直，肘抬到肩高，指尖向上
- **停留3个呼吸**

### 过渡到右侧

**吸气幻椅** → **呼气前屈按地** → **吸气抬头** → **呼气迈脚向后** → **吸气平板前移** → **呼气四柱** → **吸气上犬** → **呼气下犬**，2个呼吸。

然后**换右侧**重复：战士一 → 战士三 → 飞机战士三 → 抱膝侧展 → 鹰式（左右对调）。

> **可选加入**：如时间有余，可在此加入手臂支撑体式（如乌鸦式 Bakasana）。

## C. 核心体式详解

### 战士三式（Warrior III）

![战士三](../figures/pocketYogaImages/Standing_Mountain_tadasana.png)

*（体式图：身体成T字形，单脚站立，后腿与地面平行，双臂前伸）*

**关键对位**：
- 站立腿的膝盖微微弯曲，不锁死
- 骨盆保持水平（想象骨盆上有一碗水，不要倾斜）
- 后脚踝、膝盖、髋、脊柱、头顶在一条线上

### 鹰式（Eagle Pose / Garudasana）

**关键对位**：
- 两侧手肘都向上提，不要让手臂向下沉
- 屈膝下坐时，感受骶骨向下，背部仍然挺直
- 如果脚趾无法勾住小腿，只需让腿交叉即可

## D. 练习工具

### 自检清单
- [ ] 战士三：骨盆保持水平，深呼吸时不屏气
- [ ] 鹰式：感受上背部/肩胛骨的伸展（两侧肩胛骨相互远离）
- [ ] 平衡时：如果倒了，微笑，重来——这本身就是练习
