# 阿斯汤加开课唱诵

<p class="pose-sanskrit">Ashtanga Opening Mantra · Vande Gurūṇāṃ</p>

阿斯汤加瑜伽（Ashtanga Vinyasa Yoga）传统中，每次练习开始前唱诵的祈祷文。前半段礼敬历代**上师**（guru），后半段礼敬整理《瑜伽经》的圣者**帕坦伽利**（Patañjali）。
唱诵的意义不在宗教，而在于：带着感恩与谦卑开始练习，让心先安静下来。

## 逐句释义

| 梵文 | 意思 |
|---|---|
| *vande gurūṇāṁ caraṇāravinde* | 我礼敬上师们如莲花般的双足， |
| *sandarśita svātma sukhāva bodhe* | 它们让我们看见并觉醒于"真我"本有的喜乐； |
| *niḥ-śreyase jāṅgalikāyamāne* | 它们是至善的归处，如同丛林中的医者， |
| *saṁsāra hālāhala mohaśāntyai* | 能平息由轮回之毒所生的迷妄。 |
| *ābāhu puruṣākāraṁ* | 从手臂往上是人的形象， |
| *śaṅkha-cakrāsi dhāriṇam* | 手持海螺、法轮与宝剑， |
| *sahasra śirasaṁ śvetaṁ* | 有千个洁白光亮的头（神蛇阿南塔之形）—— |
| *praṇamāmi patañjalim* | 我向帕坦伽利顶礼。 |

**象征**：海螺 = 神圣之音（OM）· 法轮 = 光与无限的时间 · 宝剑 = 分辨的智慧 · 千首之蛇 = 无限与觉知。

## 发音小贴士

- 字母上方有横线（ā ī ū）= 长音，拖长一点。
- **ś / ṣ** 都接近"sh"；**c** 读作"ch"（caraṇa = 恰拉纳）。
- **ṁ** 是鼻音收尾，像轻轻的"嗯"。
- **jñ / ñ** 像"尼"的鼻音（patañjali = 帕坦加利）。

<div class="mantra-tip">
<b>带领提示</b><br>
· 坐姿立直，双手胸前合十（Añjali Mudrā），可以闭眼。<br>
· 传统上由老师唱一句、学生跟一句；也可以先放视频，让大家听几遍再跟唱。<br>
· 唱诵前后各唱一次 OM。<br>
· 告诉学生：可以只听、不出声，跟着呼吸感受声音就好——唱诵是邀请，不是要求。
</div>
