# 阿斯汤加结束唱诵

<p class="pose-sanskrit">Ashtanga Closing Mantra · Maṅgala Mantra</p>

阿斯汤加练习结束、大休息之后唱诵的吉祥祷文（Maṅgala Mantra）。和开课唱诵向内礼敬上师不同，结束唱诵把练习的善意**向外送出去**：愿世界公正、愿众生安乐，最后以三声"和平"收尾。

## 拉丁转写（跟唱用）

<div class="mantra"><div class="iast">oṁ<br>
svasti prajābhyaḥ paripālayantāṁ<br>
nyāyena mārgeṇa mahīṁ mahīśāḥ<br>
go-brāhmaṇebhyaḥ śubham astu nityaṁ<br>
lokāḥ samastāḥ sukhino bhavantu<br>
oṁ śāntiḥ śāntiḥ śāntiḥ</div></div>

## 逐句释义

| 梵文 | 意思 |
|---|---|
| *svasti prajābhyaḥ paripālayantāṁ* | 愿所有人都安好，愿他们受到守护； |
| *nyāyena mārgeṇa mahīṁ mahīśāḥ* | 愿治理大地的人，以公正之道行事； |
| *go-brāhmaṇebhyaḥ śubham astu nityaṁ* | 愿善良永远护佑一切神圣的生命与智者； |
| *lokāḥ samastāḥ sukhino bhavantu* | 愿所有的世界、所有的众生都幸福安乐。 |
| *oṁ śāntiḥ śāntiḥ śāntiḥ* | 和平、和平、和平。 |

**三声 śānti**：传统上分别指向三个层面的平静——自身内在、身边的人与环境、以及超出我们掌控的自然与世界。

## 发音小贴士

- **ḥ**（visarga）是轻轻的送气，像在元音后带一点"h"的回声：*prajābhyaḥ* ≈ 普拉贾比亚哈（很轻）。
- **ś** 接近"sh"：*śāntiḥ* ≈ 山提。
- **ṇ** 是卷舌 n（mārgeṇa、brāhmaṇebhyaḥ），初学按 n 读即可；**ṁ** 是鼻音收尾；字母上有横线（ā ī）的读长音。

<div class="mantra-tip">
<b>带领提示</b><br>
· 放在大休息之后：从大休息慢慢侧身坐起，坐稳后双手胸前合十。<br>
· 唱诵前后各一次 OM，最后三声 śānti 一声比一声更轻、更慢。<br>
· 唱完可以静坐几个呼吸，再一起说"Namaste"结束课程。<br>
· 同样提醒：只听、不出声也完全可以。
