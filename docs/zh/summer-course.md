# ☀️ 暑期课程 · 5节课（精修版 Compact Course）

**引言**：这个精修课延续了我们的流瑜伽串联序列，但会**分段落、更细致**地讲解与感受——分布在**五节课、每节 75 分钟**里。我们把熟悉的序列一段段拆开，每节课深入讲一个段落，最后再把它重新拼回一整套完整的流动。完整的带音乐视频在[项目首页](/zh/README.md)。

> 基本心态：这是分享和共修，不是考试。用 80% 的努力，和身体对话。 → [☯️ 瑜伽是什么](/zh/philosophy.md)

---

## A. 课程模型

**每节课都有四个环节**——这样每节课都饱满，但不会太满：
热身（呼吸调息 · 坐立热身 · 四角板凳）→ **流动**（站立与平衡序列）→ **冷却**（坐立拉伸）→ **结束**（大休息 · 唱诵）。

**每节课只精讲一个段落。** 精讲的方式就像各周章节里的*三轮*：先无音乐讲解一遍，再带音乐跟练一遍。一个精讲回合大约要花该段音乐时长的 2 倍多——所以每节课**只**深入一个大段落。

**模块化的音乐。** 序列由一条条独立音轨组成（见 C 部分）。在精讲的课上，你只播放要*复习*的那几条轨，把新段落换成慢速口述带练。完整、连续的整套流动，留到**第 5 节课**。

**时间锚点：** 四角板凳 → 大休息（带音乐）≈ **50 分钟**。75 − 50 ≈ 每节课约 **25 分钟**的余量，用于呼吸、热身、唱诵，以及*一个*精讲主题。

## B. 五节课

### 第 1 课 · 根基：呼吸与四角板凳
- **精讲**：坐立调息与四角板凳序列。
- **段落**：[第1周：呼吸与空间](/zh/week1-breathing.md) · [第2周：四角板凳式详解加流动](/zh/week2-tabletopsequence.md) · [简易坐伸展放松序列](/zh/sequences/seated-warmup.md)
- **音乐**：音轨 1 *flow_warmup*（7:06）· 音轨 7 *Savasana*（3:46）
- **课堂流程**：综述与签到（仅本节）→ 呼吸与坐立热身 → 四角板凳精讲 → 简短放松 → 大休息 · 唱诵。

### 第 2 课 · 站立序列
- **精讲**：站立序列（战士、三角、新月、蜥蜴、鸽子）。
- **段落**：[第3周：站立体式详解](/zh/week3-standingsequence.md) · [第4周：站立序列与流动（左侧）](/zh/week4-support-flow.md)
- **音乐**：音轨 1（复习，7:06）→ 无音乐慢讲单侧 → 音轨 2（9:51）→ 音轨 3 *另一侧*（9:51）→ 音轨 7。
- **课堂流程**：热身 → **流动（精讲）** → 简短冷却 → 结束。

### 第 3 课 · 平衡
- **精讲**：站立平衡体式（战士三、飞机、鹰式）。
- **段落**：[第7-8周：平衡挑战（战士三·鹰式）](/zh/week7-space-backbend.md)
- **音乐**：音轨 1 → 音轨 2（单侧复习）→ 无音乐慢讲平衡 → 音轨 4 *flow_cooldown*（7:59）→ 音轨 5（5:29，初体验）→ 音轨 7。
- **课堂流程**：热身 → 流动 → **平衡（精讲）** → 冷却 → 结束。
- *提示：这节课只精讲平衡——坐立拉伸放到第 4 课，避免一节课太满。*

### 第 4 课 · 坐立拉伸与首次完整串联
- **精讲**：坐立拉伸序列（头碰膝、马里奇扭转、指南针、反桌式）。
- **段落**：[第5-6周：前屈与中心](/zh/week5-center-fold.md) · [第9-10周：扭转·坐立·大休息](/zh/week9-twist-vinyasa.md)
- **音乐**：音轨 1 → 2 → 4（前半段用音乐串起来）→ 无音乐慢讲坐立拉伸 → 音轨 5（+ 6）→ 音轨 7。
- **课堂流程**：热身 → 流动 → **冷却（精讲）** → 结束。之后留时间做首次尝试：后弯与肩倒立（带退阶变体）。

### 第 5 课 · 跟音乐 · 一整套
- **重点**：从头到尾，跟着音乐完整走一遍。
- **段落**：全部 · [完整串联视频](/zh/README.md)
- **音乐**：**分轨 1 → 4** 连续播放，然后短暂暂停做后弯与肩倒立，再放音轨 5、6 → 音轨 7。（合并版文件用于回家不间断自练。）
- **课堂流程**：四个环节都在，不再有新的精讲。

## D. 节奏与心态

每节课我们都会用音乐重复截止到上节课练过的内容——让身体在重复中慢慢长出记忆。复习要有取舍：常常只做一侧就够，不必每次都把全部放完。

还有：宁可早收 3–5 分钟，也不要拖堂。一节安静结束的课，比塞得满满的课更有分量。大休息，永远要给够时间。

> **练习工具**：课与课之间——每天静坐 3 分钟，只观察呼吸。只要你能呼吸，就能瑜伽。
