# 侧角伸展式 · Extended Side Angle
<p class="pose-sanskrit">Utthita Parshvakonasana</p>

<div class="pose-media"><img src="figures/poses/extended-side-angle.jpg" alt="侧角伸展式"></div>

## 功效
强化腿部力量，拉伸大腿内侧和身体侧面，打开胸腔和肩膀。

## 主要顺位
- **脚部根基**：前脚尖朝前，后脚外转 90° 或微内扣，两脚跟在同一直线上。
- **腿部**：前膝屈曲成 90°，膝盖不超过脚趾、与脚踝垂直；后腿伸直，脚外侧踩实。
- **脊柱与手臂**：脊柱延展不塌陷，上方手臂贴近耳朵向斜上方伸展，与后腿成一条直线。

## 降阶 / 进阶
- 手无法触地 → 下方小臂放在前侧大腿上。
- 上方肩膀紧张 → 上方手叉腰。
- **进阶**：手从大腿下方穿过，与上方手腕相扣（束缚变体）。

## 教学口令
**步骤**
1. 上半身向前平移，小臂搭到大腿上——感受小臂向上带动大腿，而不是把重量压向大腿。
2. 反侧手臂伸展，拉开手与脚的距离。
3. 若能稳定，可将手臂伸直，放到前侧或后侧地板（或瑜伽砖）上。
4. 眼睛看向上方手臂。

**呼吸**
- **吸气**：感受侧面的伸展。
- **呼气**：下方腿更多伸展和扎根，感受大腿面与地面更趋平行。

## 常见串联
- **← 进入**：通常从战士二式（呼气侧弯）进入。
- **退出 →**：吸气用核心和双腿力量带回战士二式，或呼气双手落地进入下犬式。
