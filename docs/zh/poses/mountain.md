# 山式 · Mountain Pose
<p class="pose-sanskrit">Tadasana</p>

<div class="pose-media">▶ 视频 / 图片演示（待补充）</div>

## 功效
建立身体的根基和觉知，改善体态，培养专注力和内在的稳定。

## 主要顺位
- **脚部根基**：大脚趾球、小脚趾球和脚后跟形成稳固的三角支撑。
- **腿部**：大腿肌肉收紧上提，膝盖微屈避免超伸。
- **骨盆与核心**：尾骨自然下沉，骨盆中立，腹部微收。
- **脊柱与肩颈**：脊柱向上延展，肩膀下沉，锁骨展开。

## 降阶 / 进阶
- 双脚并拢站立不稳 → 双脚分开与骨盆同宽。

## 教学口令
**步骤**
1. 双脚并拢或与骨盆同宽站立，抬起十个脚趾，感受前脚掌和脚后跟均匀向下扎根，再将脚趾平铺回垫子。
2. 膝盖微屈避免超伸，大腿肌肉收紧上提。
3. 骨盆保持中立，微收核心，尾骨自然向下延展。
4. 肩膀向后向下沉，锁骨展开，双臂自然垂放于身体两侧，掌心向前。
5. 头顶向天空方向延展，拉长整个脊柱。

**呼吸**
- **吸气**：脊柱向上无尽延展，胸腔打开，身体充满空间。
- **呼气**：双脚掌像大树的根一样扎入大地，建立稳固的支撑。

## 常见串联
- **← 进入**：通常作为站立序列的起始体式。
- **退出 →**：吸气双手上举进入向上致敬式（Urdhva Hastasana），或呼气前屈进入站立前屈（Uttanasana）。
