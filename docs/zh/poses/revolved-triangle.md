# 反三角式 · Revolved Triangle
<p class="pose-sanskrit">Parivritta Trikonasana</p>

<div class="pose-media">▶ 视频 / 图片演示（待补充）</div>

## 功效
深度扭转脊柱，刺激消化器官，同时强烈拉伸大腿外侧和后侧（IT 带），提升平衡感。

## 主要顺位
- **脚部根基**：双脚前后分开，后脚外转约 45°，双脚脚跟可稍微错开。
- **骨盆**：保持骨盆摆正，前侧臀部向后拉，后侧臀部向前送。
- **躯干扭转**：从腹部和胸腔发力扭转，保持脊柱延展不弓背。

## 降阶 / 进阶
- 难以平衡或手无法落地 → 支撑手放瑜伽砖上，或放在前脚内侧（而非外侧）。
- 腿部紧张 → 微屈前膝。

## 教学口令
**步骤**
1. 双脚前后分开（步幅略小于三角式），后脚外转约 45°，骨盆摆正朝向正前方。
2. 吸气，抬起与前腿反侧的手臂，向上延展脊柱。
3. 呼气，从髋部折叠，上半身向前向下，反侧手放在前脚外侧地板或瑜伽砖上。
4. 保持骨盆稳定，转动胸腔向天花板打开，另一手臂向上伸展。
5. 眼睛看向地面保持平衡，或跟随胸腔扭转看向上方手指。

**呼吸**
- **吸气**：脊柱向前拉长，创造出胸腔扭转的空间。
- **呼气**：腹部向内收，加深胸腔扭转，双脚踩实保持下盘稳定。

## 常见串联
- **← 进入**：从加强侧伸展式直接进入扭转，或从高弓步扭转伸直前腿进入。
- **退出 →**：呼气解开扭转，双手落回地面进入加强侧伸展式或下犬式。
