## 2. 核心字典 (The Dictionary)
* **功效**：深度拉伸大腿后侧（腘绳肌），拉长脊柱，改善平衡感并按摩腹部器官。
* **主要顺位**：
  * **脚部根基**：双脚前后分开（步幅中等），后脚外转约45度，双脚脚跟可以稍微错开以保持稳定。
  * **骨盆**：髋部摆正，双侧髂骨朝向正前方。
  * **脊柱**：从髋关节而不是腰椎前屈，保持背部平直。
* **降阶选择 (Modifications)**：
  * 大腿后侧紧的练习者：微屈前膝，双手放在瑜伽砖上而不是地板上。
  * 如果难以保持平衡：扩大两脚左右的间距（像站在两条平行的铁轨上）。

## 3. 关键讲解与口令 (Key Explanations & Script)

### 步骤与顺位：
1. 双脚前后分开，后脚向外转约45度，双腿伸直但不锁死膝盖，骨盆摆正朝向正前方。
2. 双手叉腰，感受脊柱向上延展。
3. 从髋部折叠，保持背部平直，上半身向前向下延展。
4. 双手可以放在前腿的小腿、脚踝，或者落到两侧的地板/瑜伽砖上。
5. 感受前腿大腿后侧的拉伸，保持骨盆的稳定，不要偏斜。

### 呼吸配合：
* **吸气**：感受脊柱向前延展，胸腔打开，拉长背部。
* **呼气**：感受腹部更靠近大腿，加深前屈，双脚向下扎根稳定。

## 4. 常见串联 (Common Transitions)
* **进入**：可以从高弓步/低弓步（伸直前腿）或站立双手叉腰迈出一步进入。
* **退出**：吸气保持背部平直，双手叉腰用腿部和核心力量带起上身，或者退回到下犬式。
