# 加强侧伸展式 · Pyramid Pose
<p class="pose-sanskrit">Parshvottanasana</p>

<div class="pose-media"><img src="figures/poses/pyramid.jpg" alt="加强侧伸展式"></div>

## 功效
深度拉伸大腿后侧（腘绳肌），拉长脊柱，改善平衡感并按摩腹部器官。

## 主要顺位
- **脚部根基**：双脚前后分开（步幅中等），后脚外转约 45°，双脚脚跟可稍微错开以保持稳定。
- **骨盆**：髋部摆正，双侧髂骨朝向正前方。
- **脊柱**：从髋关节而非腰椎前屈，保持背部平直。

## 降阶 / 进阶
- 大腿后侧紧 → 微屈前膝，双手放瑜伽砖上而非地板。
- 难以平衡 → 扩大两脚左右间距（像站在两条平行铁轨上）。

## 教学口令
**步骤**
1. 双脚前后分开，后脚外转约 45°，双腿伸直但不锁死膝盖，骨盆摆正朝向正前方。
2. 双手叉腰，感受脊柱向上延展。
3. 从髋部折叠，保持背部平直，上半身向前向下延展。
4. 双手可放前腿小腿、脚踝，或落到两侧地板/瑜伽砖上。
5. 感受前腿大腿后侧的拉伸，保持骨盆稳定，不要偏斜。

**呼吸**
- **吸气**：脊柱向前延展，胸腔打开，拉长背部。
- **呼气**：腹部更靠近大腿，加深前屈，双脚向下扎根稳定。

## 常见串联
- **← 进入**：从高弓步/低弓步（伸直前腿）或站立叉腰迈出一步进入。
- **退出 →**：吸气保持背部平直，双手叉腰用腿部和核心力量带起上身，或退回下犬式。
